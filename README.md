# ممرّ — Mamarr

موقع ثابت ثنائي اللغة (عربي/إنجليزي) للوجستيات وسلاسل الإمداد في الخليج، مبني بـ [Eleventy](https://www.11ty.dev/).
لا قاعدة بيانات، لا خادم، لا تكلفة استضافة تقريبًا. تكتب المقالات بصيغة Markdown، وتحدّث الأسعار في ملف JSON واحد.

## التشغيل محليًا

```bash
npm install
npm run serve      # معاينة حيّة على http://localhost:8080
npm run build      # يُخرج الموقع الجاهز في مجلد _site/
```

## هيكل المشروع

```
src/
├── _data/
│   ├── site.json        إعدادات الموقع: الاسم، النطاق، رابط النشرة، البريد، لينكدإن
│   ├── i18n.json        كل نصوص الواجهة بالعربية والإنجليزية
│   └── rates.json       جدول أسعار الشحن (يُحدَّث أسبوعيًا)
├── _includes/           القوالب (base, article) والأجزاء المشتركة
├── ar/                  الصفحات العربية
│   ├── articles/        المقالات  ← أضف ملف .md هنا
│   └── ports/           صفحات الموانئ
├── en/                  الصفحات الإنجليزية (نفس البنية)
├── css/style.css
└── index.html           يحوّل الزائر إلى /ar/ أو /en/ حسب لغة متصفحه
```

## كيف تضيف مقالًا

1. أنشئ ملفًا في `src/ar/articles/اسم-قصير-بالانجليزي.md` بهذا الرأس:

```markdown
---
title: عنوان المقال
dek: سطر أو سطران يلخّصان المقال (يظهر في القوائم وتحت العنوان)
description: وصف لمحركات البحث (١٥٠ حرفًا تقريبًا)
date: 2026-11-15
key: same-slug
---

نص المقال بصيغة Markdown…
```

2. للنسخة الإنجليزية أنشئ ملفًا **بنفس الاسم** في `src/en/articles/`. زر تبديل اللغة يعتمد على تطابق المسار.
3. `npm run build` — المقال يظهر تلقائيًا في الصفحة الرئيسية وصفحة التحليلات مع التاريخ ومدة القراءة.

تنسيقات مدعومة داخل المقال: عناوين `##`، قوائم، جداول، اقتباس `>` (يظهر كبارز برتقالي)، و`**غامق**`.

## أسعار الشحن — قسمان مختلفان

ملف `src/_data/rates.json` فيه قسمان، ولكلٍّ طريقة تحديث مختلفة تمامًا:

| القسم | المحتوى | من يحدّثه |
|---|---|---|
| `indices` | المؤشرات العالمية: WCI, SCFI, BDI | **آليًا** كل جمعة عبر GitHub Action |
| `lanes` | أسعار الخطوط الخليجية | **أنت يدويًا** — وهي ما يميّز ممرّ |

### تشغيل التحديث الآلي (مرة واحدة)

1. سجّل في [oilpriceapi.com](https://www.oilpriceapi.com) واحصل على مفتاح مجاني (٥٠ طلبًا يوميًا — تحتاج ٣ فقط أسبوعيًا).
2. في GitHub: **Settings → Secrets and variables → Actions → New repository secret**
   - الاسم: `OILPRICEAPI_KEY` — القيمة: مفتاحك.
3. من تبويب **Actions** شغّل "تحديث مؤشرات الشحن" يدويًا أول مرة للتأكد.
4. في `rates.json` غيّر `"indices_sample": true` إلى `false` ليختفي شريط "قيم توضيحية".

بعدها يعمل كل جمعة ١:٠٠ ظهرًا بتوقيت عُمان: يجلب المؤشرات، يحدّث الملف، يتأكد أن الموقع يُبنى، ثم يدفع التغيير — وNetlify ينشره تلقائيًا.

بدون المفتاح لا يفشل شيء: السكربت يخرج بهدوء والموقع يبقى يعمل بالقيم الموجودة.

للتشغيل محليًا: `OILPRICEAPI_KEY=xxxx node scripts/update-rates.mjs`

### تحديث أسعار الخطوط (كل أسبوع، يدويًا)

افتح `src/_data/rates.json` → قسم `lanes`:

- غيّر `updated` إلى تاريخ اليوم.
- لكل خط: أضف السعر الجديد إلى **نهاية** `series` واحذف الأقدم (احتفظ بـ٨ قيم)، واجعل `usd` مساويًا لآخر قيمة، و`change_pct` نسبة التغير عن الأسبوع السابق.
- عند أول بيانات حقيقية غيّر `"sample": true` إلى `false` — يختفي شريط "قيم توضيحية".
- لإضافة خط: انسخ أي عنصر في `lanes` وغيّر `id` والأسماء. **مهم:** `slug` في `from` و`to` و`via` يجب أن يطابق ميناءً موجودًا في `ports.json` وإلا انكسر الرابط.
- `days` = زمن العبور التقريبي بالأيام. `via` = ميناء إعادة الشحن؛ احذف الحقل كله إن كانت الخدمة مباشرة.
- جدول الأسعار يفلتر بالوجهة ويبحث بالمصدر ويرتّب بالسعر والسرعة والتغير، وملخّصه (الوسيط وأكبر ارتفاع وانخفاض) يُحسب آليًا من المعروض — لا شيء منه يحتاج تحديثًا يدويًا.

## الأدوات والصفحات الإضافية

- **حاسبة التكلفة الواصلة** `/ar/calculator/` و`/en/calculator/` — معاملات الدول في `src/_data/gcc.json` (نسبة الرسم، ضريبة القيمة المضافة، سعر الصرف). راجعها سنويًا أو عند أي تغيير ضريبي.
- **الموانئ** `/ar/ports/` — كل الموانئ في `src/_data/ports.json` مصنّفة بالمنطقة. الميناء العادي تُولَّد صفحته آليًا من الملف. الميناء الذي يستحق صفحة تفصيلية: أضف `"detailed": true` في الملف، وأنشئ `src/ar/ports/<slug>.md` و`src/en/ports/<slug>.md` — عندها يتوقف التوليد الآلي ويُستخدم ملفك. لإضافة منطقة جديدة أضفها إلى `regions` أولًا.
- **معجم المصطلحات** `/ar/glossary/` و`/en/glossary/` — كل المحتوى في `src/_data/glossary.json`. لإضافة مصطلح انسخ أي عنصر واملأ `slug` و`term`/`def`/`note` بالعربية والإنجليزية و`cat` و`related`. تتولّد صفحته في اللغتين آليًا، ويدخل في البحث وخريطة الموقع. ثم شغّل `node scripts/og-images.mjs`.
- **خريطة الموقع** `/sitemap.xml` و**robots.txt** — تُولَّد آليًا، لا تحتاج صيانة.
- **خلاصات RSS** `/ar/feed.xml` و`/en/feed.xml`.
- **صور المشاركة**: بعد إضافة أي مقال جديد شغّل `node scripts/og-images.mjs` لتوليد صورته، ثم ادفع الصور مع المقال. يحتاج `rsvg-convert` وخط IBM Plex Sans Arabic مثبتًا محليًا (ليس مطلوبًا على Netlify لأن الصور تُرفع جاهزة).
- **التحليلات**: ضع رمز Cloudflare Web Analytics في `analyticsToken` داخل `site.json`. ما دام فارغًا لا يُحمَّل أي سكربت تتبّع.

## قبل الإطلاق

- [ ] `site.json` → `url`: نطاقك الفعلي (يُستخدم في روابط canonical وhreflang).
- [ ] `site.json` → `newsletterAction`: رابط نموذج الاشتراك من خدمة النشرة (Beehiiv أو Buttondown أو Mailchimp). ما دام فارغًا، يعرض النموذج رسالة "يُفعَّل عند الإطلاق".
- [ ] `site.json` → `linkedin` و`contactEmail`.
- [ ] استبدل البيانات التوضيحية في `rates.json`.
- [ ] راجع صفحة "من نحن" في اللغتين.
- [ ] `site.json` → `analyticsToken` من Cloudflare Web Analytics (اختياري لكنه مفيد).
- [ ] راجع نسب الضرائب في `gcc.json` قبل الاعتماد على الحاسبة علنًا.

## النشر (اختر واحدًا)

### Netlify (الأسهل)
1. ارفع المشروع إلى مستودع GitHub.
2. في Netlify: **Add new site → Import from Git** → اختر المستودع.
3. Build command: `npm run build` — Publish directory: `_site`.
4. اربط نطاقك من **Domain settings**. كل `git push` بعدها ينشر تلقائيًا.

### Cloudflare Pages
نفس الخطوات؛ Framework preset: Eleventy، Build output: `_site`.

### GitHub Pages
أضف ملف `.github/workflows/deploy.yml` يشغّل `npm ci && npm run build` ثم ينشر مجلد `_site` بإجراء `actions/deploy-pages`. (الموقع يعمل من مجلد فرعي أيضًا لأن كل الروابط نسبية.)

### أي استضافة أخرى
ارفع محتويات `_site/` إلى جذر الاستضافة عبر FTP أو لوحة التحكم. تأكد أن الخادم يخدم `index.html` للمجلدات (الافتراضي في كل الاستضافات تقريبًا).

## ملاحظات تقنية

- كل الروابط الداخلية نسبية (فلتر `rel` في `.eleventy.js`)، لذا يعمل الموقع من جذر النطاق أو من مجلد فرعي أو كمعاينة.
- `npm run build:preview` يُخرج نسخة في `_preview/` تنتهي روابطها بـ`index.html` لمنصات لا تدعم فهرسة المجلدات (هي النسخة المنشورة كمعاينة في Claude).
- الخط: IBM Plex Sans Arabic من Google Fonts. لاستضافة ذاتية للخط ضع الملفات في `src/fonts/` وعدّل `@font-face` في `style.css`.
- لا يوجد JavaScript سوى نموذج النشرة وزر نسخ الرابط؛ الموقع يعمل كاملًا بدون JS.

## خارطة الطريق المقترحة
